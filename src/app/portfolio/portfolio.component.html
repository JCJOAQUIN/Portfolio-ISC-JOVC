Fortia RRHH Software

Fortia Technology - Fortia RRHH Software

Fortia RRHH Software is a proprietary product of Fortia Technology, so due to confidentiality rights, I will only display images that do not include sensitive client data or internal modules.

During my time at Fortia Technology, I initially collaborated with the development team of Fortia RRHH Software following the Scrum methodology, working with technologies such as .NET with C#, SQL Server, Dapper, Entity Framework, Telerik (Kendo UI), and Azure DevOps. My responsibilities included bug fixing and the development of new modules, including a URL routing management module within the security subsystem.



Later, I joined the testing team as support, conducting manual tests on various system implementations made by other developers. I was responsible for recording video evidence of the tests and documenting the results accordingly.


After that, I became part of the special development team, where I contributed to the documentation and bug fixing of the Incidents module in the application.


Finally, I was assigned to work on the MyVacations module used by PEPSICO, where I performed several key tasks:

  • Reviewed employee data files from various countries to ensure proper onboarding into the platform.
  • Developed the “System Indicators” section, which tracks usage of the MyVacations platform by each employee, allowing the company to measure general adoption and usage effectiveness.
  • Collaborated on the multinational implementation for PEPSICO, customizing the MyVacations application to comply with the local policies and business rules of each country.
